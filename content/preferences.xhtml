How long to keep working on a single item before giving up and moving on to the next one. This is a safety net: a hung download or snapshot can't be cancelled mid-flight, so it stops one bad item from stalling the whole batch. Leave blank to use the default of 60 seconds. Raise it if you regularly pull large PDFs over a slow institutional proxy. Optional. When a PubMed ID has no DOI attached, this plugin asks NCBI's PMC ID Converter to fill it in. NCBI asks tools to supply a contact address so they can warn a heavy user before throttling them, so the only address worth sending is one you actually read. Leave this blank and no address is sent at all; the lookup still works. No API key is needed or accepted here.
